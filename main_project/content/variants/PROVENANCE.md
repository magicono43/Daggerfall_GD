# Variant declarations

`baseline.json` is project-authored metadata: an explicit baseline default for
the accepted sample block. The classic installation supplies no variant catalog.
It contains no classic payload and introduces no world reconstruction or selection
state. Variant fixture alternatives are project-authored test content published
through the checked MOD intake, using the accepted source/profile as evidence.

This project's authored variant metadata is available under the MIT license in
`LICENSE.txt`. The layout source mappings retain their separate DFU provenance
and license in `../layouts/`. No new library, format decoder or correction is used.
