## Media delivery and resource contract

The user approved direct PNG textures and WAV audio in packages with optional authoring tools on 2026-11-18. Files are explicitly mapped to logical replacement targets in package metadata. Required tool export is unnecessary for these files. Validate the actual file and expected media type before accepting a contribution.

1. **Classic adapters.** Decode source meshes, image families and media through IMP-004. Preserve source identity, geometry/texture interpretation and media timing metadata. Verify structural adapter output first. IMP-024 closes room rendering and spatial playback, and IMP-035 closes environmental music and cinematic consumers.
2. **Replacement resolution.** Resolve logical targets and equivalent classic aliases to one identity. Follow the locked configuration's precedence. Return baseline only when replacement is absent or explicit approved omission has successfully revalidated. An invalid selected resource reports provider/target/reason. A direct provider/export request cannot resolve through a different package.
3. **Resource ownership.** Cache read-only decoded resources by configuration, provider/export or logical target, source identity, converter version and result-changing variant/material/decoder inputs. Give callers independent editable material state, including mutable nested resources. Playback instances own cursor and loop state. Invalidate candidate winners after pre-menu edits and retain resources while active consumers own them.

## Required verification

- Use a known classic model and a textured placement to compare decoded topology, normals, winding, UV and orientation with the source's declared conversion. Joint rendered placement/collision acceptance closes with IMP-013/024.
- Supply a PNG with known corner colors and alpha, and a WAV with known sample values, channel count and rate. Assert decoded values and metadata. Verify a truncated or wrong-type selected file fails with provider and target context.
- Use two packages with equivalent classic/logical targets. Verify the later valid winner and contributing provenance. Request one explicit provider export and verify another package's same-named export cannot satisfy it.
- Place two consumers of one material. Mutate one instance and assert the other and cached source are unchanged. Start two playback instances and assert seeking or stopping one leaves the other intact.
- Rebuild a pre-menu candidate with changed order and verify its cache and diagnostics reflect the new winner. Reject a candidate without invalidating resources retained by another live owner.
