## Approved generation publication protocol

The user approved this protocol on 2026-11-18.

- Write a unique candidate generation beside the existing committed bundle. Finish and validate required content while the catalog still references the old generation.
- Stage one catalog revision with the new generation reference and applicable quicksave designation/numbering. Publish using the Windows storage adapter's verified replacement/recovery mechanism. Resolve uncertain publication to the authoritative catalog revision before reporting an outcome or admitting conflicting work.
- On restart, recover interrupted catalog publication before slot discovery or mutation. Uncommitted bundles cannot appear as loadable slots. Retire the previous generation after commit; report cleanup failure and retry it without changing authority.
- Delete first commits catalog removal under the same serialized mutation protocol, then cleans owned files. Pending writes must revalidate the expected slot and catalog revision and cannot republish a deleted target.

Planning-ready for the approved encoding and publication protocol. Target Windows first on Godot 4.7.2. Execution waits for IMP-002/003/017 and authorization. Verify the storage adapter's concrete filesystem operations with interruption and reopen fixtures before publication acceptance.
