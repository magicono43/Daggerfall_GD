## Locale and schema contract

- First launch selects bundled English. Players can explicitly select validated installed languages. A text key retains the base-language declaration of its original definition when a translation is replaced. An added key declares its own base language. Persist locale selection through CORE settings.
- Locale identity is an explicit catalog identifier. Resolve declared identifiers exactly; regional or neighboring-language fallback requires an explicit content mapping. Translation lookup returns selected, base, source, optional suppression, missing ordinary text, or essential fallback plus key/source diagnostic context.
- Keep catalog validation distinct from per-entry usability. A malformed CSV or duplicate target rejects the contribution. A valid sparse table can omit entries. Blank entries fall back unless optional suppression is explicitly supported. Essential labels cannot be suppressed. Each required placeholder must survive translation with its supported type/format.
- The token codec retains literal text and meaningful spaces, typed controls with operands, variant boundaries and source identity. Preserve line/page breaks distinctly from editorial wraps. Require explicit escaping. Unsupported required controls fail conversion with record/token context. Never silently flatten them.
- Freeze schema and codec version in the first increment's fixtures. Concrete serialization field names and escape spellings can be selected during implementation, documented alongside their parsers, and verified by structural round trips before authoring export is accepted.
- Locale/role mappings validate referenced resources and reject fallback cycles. Verify body, title and small-UI roles and the actual recovery labels. Script-rendering fixtures exercise combining marks and right-to-left layout. Supported-language advertising waits for that language's actual catalog, fonts and layout acceptance.

## Acceptance

- Use bundled English and a small synthetic second locale with explicit per-key expectations. In that locale include a valid reordered-placeholder entry, missing and blank entries, and a malformed required placeholder. Verify respectively selected text, English fallback, English fallback and diagnosed usable fallback. Supply a key whose base language is the synthetic locale and verify replacing another translation preserves its base declaration.
- Exhaust ordinary fallback and verify a visible placeholder with collection/key/locale provenance. Remove optional catalogs and classic access, then verify Retry, Quit, Choose Folder and required recovery choices still have readable bundled labels.
- Apply two ordered valid patches and verify winning provenance. Make a later row in one contribution invalid or duplicate its target. Verify that none of that contribution publishes. Extra source files and unrelated valid catalog entries remain governed by the existing contribution rules.
- Decode a known TEXT.RSC record and explicit synthetic records containing meaningful leading/trailing spaces, literal escape characters, two variants, line and page boundaries, and required interaction controls. Export and reimport each supported record, comparing token order, operands and boundaries under documented normalization. An unsupported required token fails with its source position.
- Switch locale while a choice window is pending. Verify the stable selected answer, pending operation, focus, RNG draw count and reward/quest state are unchanged while the displayed text refreshes.
- Verify font fallback with mixed text and combining characters, a missing glyph with a visible marker, a rejected cyclic chain, and right-to-left ordering in the rendered suite. Reflow long labels without clipping required instructions. Use test strings and expected reading order, and record inspected rendered output.
- Preview an unchanged reimport and verify zero duplicates or needless updates. Change a source placeholder or remove a mapped source entry and verify retained translation and review state. A rejected selected import commits zero changes. Existing translations remain intact unless their replacement was selected.
- For a fixture mod with live and restart-required preference groups, stage a partial preset, cancel it, confirm and cancel a defaults reset, then Apply. Check effective and pending states, persisted values per mod/root, recovery after write failure, and stable setting identity after locale change.
