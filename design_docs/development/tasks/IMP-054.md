## Approved inspection increments

The user approved this breakdown on 2026-11-18.

1. **Source browser.** Inspect text/definitions, static models and textures with stable identity, source and conversion metadata through runtime readers.
2. **World preview.** Render resolved exteriors, interiors/dungeons and nearby terrain using an independent preview camera and selection. Display optional boundary/entrance/collision overlays and available validator warnings. Preview does not mutate gameplay state.
3. **Export.** Write supported editable definitions, static meshes and PNG textures to an explicit workspace. Use IMP-008's GLB/PNG media profiles and owner-defined data schemas. Disclose conversion losses and obtain explicit confirmation before replacing files. Validate supported unedited reimports with the production loader.

## Preview/export fixture

Use one source definition, model/texture and location layout with a missing optional resource. Report partial-preview omissions and identity/provenance without falsely claiming full support. Byte-exact classic record export remains outside initial scope under DEV-009.

IMP-055 uses these previews in authoring; IMP-056 reuses validators for packaging. Workspace exports remain separate from original data and the locked runtime configuration.

## Constraints and readiness

Planning-ready for the approved three increments. Target Windows first on Godot 4.7.2. Execution waits for IMP-008/013/025 and authorization. Record supported schema fields and conversion losses with each export profile.

## Acceptance

- Browse and preview pinned model/texture/definition sources and compare stable identity, provenance and transforms with runtime reader output.
- Select objects in a resolved location and inspect overlays. Repeated camera/selection operations leave owner state and live RNG unchanged.
- Remove an optional preview resource and verify disclosed partial output and validator diagnostics rather than false readiness.
- Export GLB/PNG and supported editable records, reimport unchanged and compare represented geometry/pixels/fields. Record declared conversion losses.
- Attempt overwrite and cancel confirmation. Assert the original workspace file survives. Reject invalid export/reimport with source/key context.
- Verify original ARENA2 and active runtime catalogs are untouched by inspection and export operations.
- Verify the accepted and rejected outcomes specified by the linked feature criteria; record which criteria are covered by owner tests and which require a milestone integration run.
- Confirm that required handoff results reach the expected consumer and that rejected or obsolete input leaves committed state consistent under the approved failure policy.
