## Approved legal-resolution increments

The user approved this breakdown on 2026-11-18.

1. **Court.** LAW owns the accepted case, plea/debate/lie resolution, penalty and eligible guild rescue under LAW-011/012/013/014. UI submits stable choices and displays owner outcomes. Revalidate case and eligibility at commitment; preserve resolved draws and costs.
2. **Custody and release.** TIME advances the authorized sentence and release intervals under LAW-015's explicit skipping and boundary policies. LAW owns custody state. WORLD/MOVE commit validated release placement before control returns.
3. **Persistence.** Capture legal state and supported court/custody progress, committed payments and outstanding obligations. Restore without rerolling retained decisions, reapplying penalties or advancing elapsed sentence time again.

- Reject invalid release placement and verify custody/recovery and input gates remain truthful. Valid release commits one location/pose and releases only the proper holds.
