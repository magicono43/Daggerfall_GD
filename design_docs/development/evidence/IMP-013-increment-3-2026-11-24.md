## Implemented scope

The normal shell composes one MOVE `placement_authority.gd` with the existing
single LOC owner and CORE. MOVE owns the real `CharacterBody3D`, active capsule,
pose and supported standing physical state. It consumes the original marker
handoff, original CORE operation, separate activation session, bound entrance,
actual exit and canonical return, and retains intended movement space/door side.
No second location registry or lifecycle exists. Existing actor/shape authority
was absent: repository inspection found no other runtime CharacterBody/capsule
provider to reuse. This focused owner supplies placement without locomotion.

Full Jolt shape intersection and shape-sweep support/contact checks precede
commitment. LOC lends the correct isolated prepared or activated physics space;
MOVE never substitutes a ray/marker-ready flag for clearance. All solid layers
participate, including current occupants/mechanisms; nothing is shoved or made
non-solid. Exact requested actor pose precedes declared deterministic local
candidates. Ground absence and excessive slope are checked failures. Corrections
require a full-shape free route and stay on the bound door side. Initially
overlapping starts fail conservatively; penetration-escape correction remains
unavailable. The supported profile can correct a local support gap, and does not
pretend every blocked marker is recoverable.

DATA owns the replaceable numeric definition in `content/layouts/placement.json`
and validates optional complete `location_assembly.placement_policy` replacements
through existing MOD/loose precedence. LOC captures/fingerprints that small
projection once per preparation. The baseline capsule is radius 0.30 m, height
1.80 m, query margin 0.005 m, support depth 0.08 m, maximum support slope 45° and
maximum correction distance 0.60 m. See the [owner contract](../../../main_project/scripts/move/PLACEMENT.md)
for envelopes, candidate order and exact conversion provenance. No DFU controller
constants were adopted. The classic geometry/scale/UV profiles and source records
are unchanged; all 256 independent ground checks remain maintained.

Source anchors remain separate from actor centres. The declared conversion
preserves interior inward depth/sole height, fits the lateral centre inside the
actual bound aperture with capsule clearance, then adds half-height and margin.
Exterior anchors use the actual doorway's bottom height. Conversion displacement
is explicit and bounded. Independent expected classic centres in metres are:

Commitment requires the active original CORE operation and activated handoff,
current access, fresh shape validation and unchanged scope after callbacks. The
real body's shape/pose and supported state publish once. Reentrant commits reject;
duplicates retain their receipt and changed duplicate inputs reject. The existing
view owner applies facing, clears pending look input and resets interpolation.
Doorway-only state initialization cannot clear unsupported fall/native history.

CORE's operation hold now includes save alongside simulation/input. After MOVE
joins an operation, CORE rechecks its exact committed placement against current
geometry before accepting readiness. Placement alone releases no gate or other
owner's hold. Ordinary preparation calls no TIME/activity/effect advancement.
Preactivation cancellation retains source pose/context. If activation retired the
source, subsequent failure uses CORE cleanup/recovery and never claims rollback.
