During development, realistic 64-block stress exposed two integration defects
that small fixtures missed. One-body-per-model exceeded Jolt's boot limit of
10,240; fixed geometry now uses per-occurrence compound bodies, with independently
addressable shape owners, while doors/action records/action targets stay separate.
The 10,304 model instances use 1,088 bodies. Rebuilding repeated render meshes also
exhausted D3D12 allocations. Immutable mesh/shape prototypes now build once per
effective model/preparation, with independent placed materials/transforms. Blocks
can advance between frames. Tests assert the last occurrence's actual collision,
one unique build per model, capacity rejection/cleanup and detached scoped queries.
No engine limit was increased or diagnostic whitelisted to hide these failures.

The synthetic 64-block arrangement is deliberately disconnected and measures
assembly scale, not navigation or destination readiness. Reported elapsed/query
times and memory are observations, not invented acceptance budgets. The low-cap
fault injection runs last because Jolt may cache settings across worlds in one
process; a fresh process retains the unchanged project limit.
