## Implementation

One SessionShell physics coordinator consumes existing resolved continuous intent
and scoped edges, actual view yaw, narrow coherent CHAR capabilities and current
collision context. It advances the existing MOVE capsule with actual collision
sweeps; it creates no second body, camera-facing authority, input map, actor store,
clock or CORE. Actual/requested travel and gait/target speed remain distinct.

The ground DATA adapter publishes the approved standing MOVE-005 constants and
metre mapping through existing shipped/MOD/loose precedence and content locking.
The focused float RULE hook uses the existing checked registry and required bound
consumer, with no fallback on selected provider failure. Separate source-owned
Walk/Run/Sneak factors use deterministic bounded log-domain combination and a
checked final cap. Vanilla adds no encumbrance movement penalty or sprint meter.

Stock Controls applies independent Hold/Toggle Run and Sneak. Defaults remain
Hold/Hold; Crouch remains retained Toggle with its posture owner pending. Autorun
is a rebindable synthetic forward/Run request and never rewrites preferences.
Input contributor, GUI refusal, device/deadzone/keyboard priority and once-only
edge ownership stay with IMP-011. CORE pause preserves physical history and adds
no elapsed catch-up. Current intended rate scales eligible simulated delta; zero
rate advances nothing, and unsupported scaled steps fail checked.

CHAR retains fatigue, raw practice, fractional cadence and exhaustion authority.
MOVE captures actual collision outcomes, scoped source revisions and original
eligible clocks. Performed actor-write custody prevents callbacks/later writes
invalidating unsettled work. Failed delivery retains up to two ordered segments,
holds unsafe advancement and retries without moving again. Context-compatible
steps batch before first intake; admitted requests and CHAR receipts remain
immutable. Original physical capability revisions are distinct from the queued
segment's first expected CHAR admission revision. Pure CHAR prediction forces
settlement on the depletion step without writing resources/receipts or using RNG.

The first prototype submitted one interval per physics step and would exhaust
the accepted 4096-record retention ceiling after about 68 eligible seconds at
60 Hz. That was identified during implementation and replaced with elapsed/context
segmentation. The sustained 5,000-step / 83⅓-second vector requires 84 new records,
including its partial flush. The existing finite retention/checkpoint boundary is
still enforced before new travel; no eviction, reset or native SAVE readiness is
invented.

See [GROUND.md](../../../main_project/scripts/move/GROUND.md) for exact schemas,
units, numeric bounds, source lifetime, reset/custody/proof contracts, unsupported
mode handoffs, course dimensions, provenance/licensing and integration obligations.
No library/toolchain/platform adapter change or external data mutation occurred.
