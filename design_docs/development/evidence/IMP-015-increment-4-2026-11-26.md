## Provenance and intentional differences

The [identity contract](../../../main_project/scripts/char/CREATION_IDENTITY.md)
records schema, arithmetic, control policy, engine/ICU pin, stable IDs and source
receipts. `tools/build_creation_identity.py` extracts eight humanoid banks from
pinned DFU NameGen.txt; its malformed unused Monster3 tail is excluded without
mutating the source. Argonian uses DFU's explicit Imperial mapping; PCG preserves
composition/probabilities rather than Unity's RNG sequence. DFU licensing remains
in `content/char/DFU_LICENSE.txt`; original game art/video/palettes are not added.
Reference material, classic installation and base data remain read-only.

Windows export qualification caught omitted Unicode support data: the stock
template advertised break iterators but counted combined characters as code
points. `project.godot` now includes TextServer data, as documented by
[Godot](https://docs.godotengine.org/en/stable/tutorials/i18n/internationalizing_games.html).
The exported 31/32-boundary vectors qualify that fix independently of editor tests.

The affected replacement suite also exposed a reentrant composition defect:
`prepare_content()` staged formula preparation before DATA rejected an active
menu-commit reservation, changing the required `busy` outcome to
`formula_preflight`. DATA now exposes a read-only `preparation_gate()` reused by
its own prepare and the composition boundary. Busy/locked requests reject before
adjacent staging or catalog preparation. The existing maintained “reserved media
rebuild rejected” boundary assertion caught and qualifies this correction.
