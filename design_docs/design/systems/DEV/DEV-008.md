# DEV-008 — Classic save inspection

**Review status — Deferred by user decision on 2026-11-18.** See DEV-008-D01 in the [decision log](../../GAMEPLAY_DECISIONS.md).

Defer standalone inspection of classic saves until a specific record or behavior requires investigation. The approved [native save policy](../CORE/CORE-013.md) and [classic import scope decision](../SAVE/SAVE-018.md) still govern session loading.

If a concrete need arises, define the records to inspect, supported classic formats, read-only access, export scope and handling for malformed or unsupported files before proposing a tool.

## Daggerfall Unity reference

The Unity Editor's Save Explorer uses `SaveGames` and `SaveTree` to inspect classic save slots and can export selected record bytes. It displays the save image, character data, factions, items and the record tree.
