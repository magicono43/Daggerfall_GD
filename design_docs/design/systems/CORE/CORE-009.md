# CORE-009 — Worldless startup

Review status: **Deferred by user decision on 2026-11-05.**

## Decision and rationale

Defer this feature until a clear purpose emerges. The user stated: “defer CORE-009 until a clear purpose for it shows up.” Reference: CORE-009-D01 in [the decision log](../../GAMEPLAY_DECISIONS.md).

DFU's StartVoid disables normal world parents and sets NoWorld, but its intended use has not been established. The startup castle backdrop uses the setup wizard's separate CreateBackdrop path (CUSTAA06.RMB), so that backdrop does not establish a need for worldless startup.

## Scope and reconsideration

This is a deferral record, not a completed feature specification or permanent exclusion. Reopen review when a concrete gameplay, authoring or testing need is identified. At that point establish purpose, consumers and interactions with approved lifecycle rules before defining behavior.

Earlier suggestions about development-only access, storage and lifetime were recommendations, not accepted requirements. No worldless mode, player sandbox or castle-backdrop requirement is approved by this decision. No implementation or coding tasks are authorized or produced.
